# TODO

Задачи уровня репозитория: соглашения, документация, инфраструктура, новые
тулзы. Пишем сюда оба — и пользователь, и Claude.

> **Правило работы со списком.** Этот файл — только хранилище задач.
> Claude не берёт отсюда ничего в работу по собственной инициативе: ни при
> «заодно поправь», ни когда задача выглядит тривиальной, ни когда она рядом
> с тем, что уже правится. Работа над пунктом начинается только по явному
> указанию пользователя на конкретный пункт. Без такого указания файл можно
> читать и дополнять, но не исполнять. То же правило действует для списков
> отдельных тулз.

## Списки тулз

## Как писать пункты

- Один пункт — одна задача, чекбоксом `- [ ]`.
- Задача про конкретную тулзу — в `TODO.md` этой тулзы, не сюда.
- Формулируйте так, чтобы через месяц было понятно без контекста беседы.
- Сделанный пункт удаляется из файла; след остаётся в `CHANGELOG.md` и в git.
