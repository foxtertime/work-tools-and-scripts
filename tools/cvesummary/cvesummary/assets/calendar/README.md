# Производственный календарь РФ

Резервные копии XMLCalendar для пятидневной рабочей недели, загружены 09.11.2026.
Источник: https://xmlcalendar.ru/data/ru/{year}/calendar.xml
Описание формата: https://github.com/xmlcalendar/data

В XML перечислены исключения к обычным Сб/Вс: 1 — нерабочий день,
2 — сокращённый рабочий день, 3 — рабочий день по переносу. В cvesummary
сокращённый рабочий день пока считается полным (8 часов).

CLI автоматически обновляет календарь, кеширует его на 7 дней и использует
эти копии при недоступности сети и отсутствии подходящего кеша.
