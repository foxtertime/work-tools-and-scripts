# Task drilldown implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved prototype transfer inline.

**Goal:** Перенести одобренный список задач из прототипа в cvesummary.

**Architecture:** Изолированный JS-модуль подключается после отрисовки
сводки, открывает модальный список и восстанавливает привязки при обновлении
разрезов. Чистые функции отвечают за поиск, сортировку, CSV и выбор строк AI.

**Tech Stack:** Python 3.9+, стандартная библиотека; браузерный JS/CSS;
`unittest`, `node:test`, Playwright только для проверки в браузере.

**Spec:** `../specs/2026-10-26-drilldown-design.md` — проверенный пользователем вариант.

## Global Constraints

- Один автономный HTML, без новых зависимостей при использовании.
- По 50 строк; CSV содержит всю найденную выборку.
- Пары AI и пересекающиеся основания сохраняют существующий учёт.
- Затемнение без `backdrop-filter`.
- Рабочая ветка `feature/cvesummary-drilldown`, версия тулзы 1.22.0.

## Review Focus

- Пустые данные и отсутствие AI не ломают страницу.
- Пропущенные значения сортируются после известных, включая ноль.
- Дубли с разными прогонами и одинаковые remediation в разных группах.
- CSV с кавычками, переводами строк и формулами из входных ячеек.
- Повторное открытие, смена разрезов, Escape, возврат фокуса и прокрутка.
