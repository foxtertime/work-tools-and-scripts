# CVE forecast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Согласовать прогноз всего объёма с графиками и показать остаток,
запас и сценарии к релизу.

**Architecture:** Общий дневной расчёт в `pace.js` обслуживает simulate,
project и планирование. Чистые forecast/scenarios возвращают результаты
для существующего DOM-renderer.

**Tech Stack:** Python 3.9+ stdlib, browser JavaScript, node:test.

**Spec:** `../specs/2026-10-26-forecast-design.md`

## Global Constraints

- Python 3.9+, стандартная библиотека; один автономный HTML, без новых зависимостей.
- Новые задачи поступают каждый календарный день; закрытие — Пн–Пт,
  праздники не учитываются. Сканфриз — первый день без новых задач.
- Существующие незакоммиченные изменения сохраняются; общий коммит с ними не создаётся.

## Review Focus

- Временный ноль до сканфриза: график продолжает учитывать поступления.
- Нулевой сегодняшний остаток: будущая работа присутствует и в плане.
- Цель в выходной: поступления после последнего рабочего дня нельзя закрыть заранее.
- Без сканфриза: все режимы одинаково сообщают неопределённость завершения.
- Пустые/короткие окна и дальняя цель: нет NaN и неограниченных циклов.
