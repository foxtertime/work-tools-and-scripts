# Производственный календарь РФ

Праздники и переносы должны учитываться в рабочих днях, часах, темпе,
перерывах и прогнозе. 04.11.2026 исключается из знаменателя скорости.
Фактическое начало/окончание задачи в нерабочий день по-прежнему означает
работу разработчика; поступление остаётся по календарным дням.

Источник — XMLCalendar RU, пятидневка. CLI получает годы истории до года
отчёта и следующий год, кеширует XML на 7 дней в XDG_CACHE_HOME/cvesummary
(по умолчанию ~/.cache/cvesummary). При недоступности сети использует старый
кеш, затем встроенные 2025–2027 годы; при отсутствии данных явно сообщает
годы и применяет Пн–Пт. Для прогноза вне загруженных лет также указан fallback.
Данные и названия праздников встраиваются в автономный HTML. Содержание
таблицы в сеть не передаётся. Сокращённый день остаётся 8-часовым по прежней
модели. Регионы и индивидуальные календари вне этой задачи.

Общий модуль dates хранит календарь; isWeekend сохраняет смысл Сб/Вс,
новый isNonWorking используется всеми расчётами и фоном графиков. На фоне
праздника подсказка с датой и названием. Видимая подпись у темпа сообщает
покрытые годы и правило для остальных лет. page.render остаётся чистым:
календарь передаёт CLI; без него сохраняется режим Пн–Пт для прямых вызовов.

Сохраняются правила приоритета общего перерыва, ревью с End date, SecOps
и исключения убранных задач из пула. Нет новых зависимостей.
