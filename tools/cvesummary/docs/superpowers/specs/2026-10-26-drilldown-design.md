# Списки задач из показателей сводки

Пользователь проверил прототип в `/tmp` и одобрил перенос в cvesummary
2026-10-26, включая исправление медленной прокрутки.

## Поведение

Клик по счётчику или сегменту открывает модальное окно со строками, из
которых рассчитан показатель. В нём есть поиск по полям, сортировка по
заголовкам, ссылки на CVE, страницы по 50 строк и CSV всей найденной
выборки. CSV сохраняется в UTF-8 с BOM, разделителем `;`, экранированием
кавычек и защитой от исполнения формул из содержимого ячеек.

Входы: шапка, критичность, меры, RHEL, статусы, основания закрытия,
компоненты, разработчики, аномалии, AI и remediation. Для AI сохраняются
пары CVE + компонент и выбор самого свежего вердикта; одинаковые названия
remediation из разных групп не объединяются. В сегментах шапки сохраняется
учёт по первому основанию, в разрезе оснований — все подходящие строки.

Окно закрывается крестиком, Escape или кликом по фону; фокус возвращается
к вызвавшему элементу. Работают клавиатура, узкий экран и тёмная тема.
Фон затемняется без размытия: `backdrop-filter` замедлял прокрутку.

## Подход

Выбран проверенный модальный список: он сохраняет место в сводке и
позволяет изучить выборку без изменения показателей. Отдельная страница
потребовала бы повторной навигации; общие фильтры всей сводки выходят за
рамки этого переноса.

Переносится автономный JS-модуль и стили, без новых зависимостей или
сервера. Расчёты сводки и входной формат сохраняются. Глобальные фильтры,
карточка отдельной задачи и новые метрики в этот перенос не входят.
