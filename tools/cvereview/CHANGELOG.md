# Changelog

## [Unreleased]

## [0.4.1] - 2026-11-15

### Изменено

- На кнопке RHSA отображается полный ID advisory из ссылки,
  включая ссылки с закодированным двоеточием.

## [0.4.0] - 2026-11-15

### Добавлено

- Фильтр по статусу разработчика: все, «Ожидает ревью» или «Готов».
  Работает во всех пулах вместе с поиском и остальными фильтрами,
  сохраняет отметки и возвращает на первую страницу результатов.

## [0.3.0] - 2026-11-15

### Добавлено

- Поиск по всем значениям CSV, включая дополнительные колонки, сборки,
  даты, ссылки и AI-поля, а также по замечаниям и чеклистам текущего
  и предыдущего ревью. Закрытые подробности тоже участвуют в поиске.
- Индекс значений кешируется; поиск остаётся отзывчивым на 5000 строках.
  Результаты актуализируются после изменения отметок без их потери.

## [0.2.1] - 2026-11-15

### Изменено

- Адрес тасктрекера задаётся в настройках по аналогии с GitLab;
  встроенный адрес по умолчанию удалён. До настройки переход недоступен,
  пустое значение сохраняется без обратной подстановки старого адреса.

## [0.2.0] - 2026-11-15

### Изменено

- Заданы 11 пользовательских наборов с короткими формулировками, от 2 до 9
  пунктов: бэкпорт, обновление, тегирование, ребилд Go и остальные меры.
- Справочник вынесен в отдельный JSON и встраивается в автономный HTML.
  Сохранены варианты прежних названий мер для существующих CSV.
- Отметки сопоставляются по постоянным ID: переименование/перестановка
  сохраняют результат; новые пункты требуют проверки; удалённые остаются
  в предыдущем ревью. Старые JSON и кеш читаются с сохранением истории.
- Полный список формулировок воспроизводимо собирается в docs/checklists.md.

## [0.1.1] - 2026-11-14

### Изменено

- Кнопка завершения и пул проверенных задач называются «Проверено».
  Обновлены рабочая страница, все прототипы и документация.

## [0.1.0] - 2026-11-14

### Добавлено

- Автономный HTML: загрузка CSV vulnsheet, карточки разработчиков
  со статусами «Ожидает ревью» и «Готов», исключение SecOps.
- Компактный столбик карточек 3:1 с чеклистами по 11 мерам,
  тремя состояниями пунктов, пулами проблем/проверенных и отменой.
- JSON состояния и кеш в браузере, сопоставление по Task ID/CVE/компоненту,
  повторное ревью изменившихся задач с историей и архивными решениями.
- Настраиваемые ссылки тикета/GitLab, условная RHSA, CVE, поиск,
  фильтры, сортировка, страницы по 50 карточек и мобильная раскладка.
- CSV UTF-8/Windows-1251, три разделителя, кавычки, многострочные поля,
  диагностика колонок и конфликтов идентичности.
- Воспроизводимая сборка, встроенные шрифты/лицензии, пример CSV,
  модульные и браузерные проверки; сохранены пять UI-прототипов.
