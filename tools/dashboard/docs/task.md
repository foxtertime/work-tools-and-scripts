python скрипт, который агрегирует данные из koji и gitlab и делает фронтенд html дашборд.
на вход скрипту передается тег (один или несколько), далее скрипт по тегу скрипт запрашивает у коджи список лейтест билдов (в том числе с наследованием).
для каждого билда собирается полная информация о нем. особенно интересует поле Extra, которое содержит информацию о ветке гитлаба, из которой данный билд собран.
пример Extra: {'source': {'original_url': 'git+ssh://git@gitlab.com/group/repo?#origin/branch-name'}}
из этого пути достаем название ветки.
для каждого билда опрашивается гитлаб по url и названию ветку получается дерево каталогов, нас интересует наличие в корне каталога PATCH.
если он есть, то собираем названия файлов внутри и классифицируем их. это могут быть SAST, DAST, CVE патчи и другие.
дашборд сверху блоки со счетчиками всякими имеет, ниже таблица со всеми билдами тега. каждый раскрывается и можно посмотреть инфу о нем, из какой ветки, какие патчи имеет.
должны быть фильтры, должны быть теги таблицы (не путать с коджи тегами).
если было передано несколько коджи тегов, то дашборд дополнительно должен показывать, что поменялось между ними. какие патчи ушли, какие пришли, как версия билда поменялась, как пакеты внутри билда поменялись (какие добавились, какие убрались).
придумай как это сделать чтоб было удобно, мб доп вкладка или еще что-то.
ОБЯЗАТЕЛЬНО используй плагины superpowers для разработки и frontend-design для дизайна.
т.е. открыв такой дашборд мы должны понять, какое состояние у тега сейчас. что есть, какие патчи и т.д. и при необходимости сравнить с другим тегом (тегами).
