## Баги

- [ ] **BUG-H-2611-01**
      Область: `dashboard/httpclient.py`, `HttpTransport.get`;
      `dashboard/gitlabclient.py`, заголовок `PRIVATE-TOKEN`.
      Автоматические HTTP-редиректы пересылают токен GitLab на другой
      origin: `requests.Session.get` вызывается без ограничения редиректов,
      а пользовательский заголовок `PRIVATE-TOKEN` сохраняется. Проверено
      двумя локальными HTTP-серверами: запрос к `127.0.0.1` с фиктивным
      токеном получил 302 на `localhost` с другим портом; второй сервер
      получил тот же токен, транспорт вернул 200. Обрабатывать редиректы
      явно: при смене origin не отправлять секрет; учитывать также переход
      с HTTPS на HTTP и возвращать понятную проблему билда.
      Источник: ревью и локальное воспроизведение без внешних сервисов
      (2026-11-02).
      Приоритет высокий (2026-11-02): редирект с настроенного API может
      раскрыть действующий токен постороннему серверу.

- [ ] **BUG-M-2611-02**
      Область: `dashboard/assets/js/diff.js`, `pathShas`, `diffSnapshots`;
      `dashboard/assets/js/viewmodel.js`, `diffRow`.
      Ошибка чтения PATCH превращается в выдуманное удаление патчей:
      сравнение не учитывает `patch_dir_present: null`, а пустой `patches`
      принимает за достоверное отсутствие файлов. Воспроизведение в Node:
      сравнить два снапшота одного NVR; в первом `patch_dir_present: true`
      и патч `PATCH/fix.patch`, во втором `patch_dir_present: null`,
      `patches: []`, `problems: [{level: 'error', text: 'gitlab: 503'}]`.
      `diffSnapshots` выдаёт `patches_removed: ['PATCH/fix.patch']`,
      `changed: true`; обратный порядок выдумывает добавление. Вкладка
      «Изменения» не передаёт проблему чтения в строку и показывает это
      обычным диффом. Сохранять неизвестность отдельно от пустого дерева,
      не считать по ней изменения патчей и показывать причину.
      Источник: ревью и локальное воспроизведение на двух объектах снапшота
      (2026-11-02).
      Приоритет средний (2026-11-02): обычный отказ GitLab искажает ответ
      о наличии исправлений и сводные счётчики изменений.

- [ ] **BUG-M-2611-03**
      Область: `dashboard/collect.py`, `_branch_drift`;
      `dashboard/gitlabclient.py`, `_fetch_compare`.
      При `compare_timeout: true` клиент сохраняет известный `head`, но
      возвращает `ahead: None`; проверка `if not commits_ahead` прекращает
      работу до чтения дерева ветки. Из-за неизвестного числа коммитов
      теряются доступные различия деревьев и ghost-патчи, без проблемы
      или предупреждения. Проверено фейковым транспортом: коммит сборки
      `a…a` содержит `PATCH/old.patch`, ответ сравнения указывает иной
      `head: b…b`, ветка содержит `PATCH/new.patch`. Без таймаута получены
      два ghost-патча и три запроса; с теми же данными и таймаутом — пустой
      список, два запроса и пустой `problems`. Решать, нужно ли сравнивать
      деревья, по известным SHA, независимо от доступности счётчика;
      снимать дерево с зафиксированного `head`.
      Источник: ревью и локальное воспроизведение через `_attach_patches`
      с фейковым HTTP-транспортом (2026-11-02).
      Приоритет средний (2026-11-02): на длинной истории молча пропадают
      сведения о патчах, которые ещё не вошли в пакет.

- [ ] **BUG-M-2611-04**

- [ ] **BUG-M-2611-05**
      Область: `dashboard/assets/js/diff.js`, `byName`;
      `dashboard/assets/js/viewmodel.js`, `bump`, `snapshotCounts`;
      `dashboard/assets/js/text.js`, `keys`.
      Словари `{}` не сохраняют часть допустимых ключей из данных.
      Воспроизведение: `diffSnapshots` для двух снапшотов с компонентом
      `name: '__proto__'` возвращает пустой `components` — присваивание
      меняет прототип вместо создания записи. Патч класса `__proto__`
      аналогично даёт пустые `patch_counts` и `counts.by_class` при
      непустом списке патчей. Класс `hasOwnProperty` перекрывает метод,
      используемый в `text.keys`, и ломает отрисовку. Конфиг принимает
      оба имени класса; проверки собственного свойства при чтении не
      защищают присваивания. Использовать `Map` или объекты без прототипа
      и безопасный вызов `Object.prototype.hasOwnProperty.call`.
      Источник: ревью, проверка `load_config` и локальное воспроизведение
      вычислений страницы в Node (2026-11-02).
      Приоритет средний (2026-11-02): компонент или класс молча исчезает
      из результатов; для другого разрешённого класса файл не показывается.

- [ ] **BUG-L-2611-06**
      Область: `dashboard/assets/js/text.js`, `slug`;
      `dashboard/assets/js/viewmodel.js`, `buildMarks`;
      `dashboard/assets/js/labels.js`, `setClasses`, `groups`;
      `dashboard/assets/js/page.js`, фильтры классов.
      Разные разрешённые имена классов получают одинаковый ключ фильтра.
      Проверено для `C++` и `C#`: конфиг принимает оба, `slug` превращает
      оба имени в `c-`; при двух билдах с разными классами выбор карточки
      `C++` показывает оба, хотя её счётчик равен одному. Подпись фильтра
      также перезаписывается последним классом. Имена классов могут
      пересечься и со служебными ключами вроде `warning`. Ввести уникальные
      ключи классов в отдельном пространстве имён либо явно отклонять
      неоднозначный конфиг до сбора, с учётом старых снапшотов.
      Источник: ревью, проверка `load_config` и локальное воспроизведение
      `page.visibleRows` в Node (2026-11-02).
      Приоритет низкий (2026-11-02): затронуты пользовательские классы с
      совпадающими ключами; стандартный набор классов различим.
