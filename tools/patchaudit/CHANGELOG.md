# Changelog

## [Unreleased]

## 0.2.0 - 2026-11-01

### Добавлено

- Сравнение целевых SL-релизов с Red Hat: `sl` преобразуется в `el`,
  конечный суффикс пересборки `^<номер>` отбрасывается. Например,
  `26.sl9_8^3` соответствует `26.el9_8`; исходный NVR в JSON сохраняется.

## 0.1.0 - 2026-11-01

### Добавлено

- Проверка CVE-патчей из PATCH ветки последнего билда в Koji-теге по Red
  Hat CSAF/VEX. Два режима: доступные фиксы по имени пакета и рекомендации
  по целевому NVR с отдельной категорией для последующего обновления.
- JSON с решениями по CVE и файлам, версиями, датами и errata фиксов;
  неполные данные и ошибки выделяются явно. YAML-конфиг, CLI, атомарная
  запись файла и офлайн-тесты.
