## Баги

- [ ] **BUG-M-2611-01**
      Область: `taskhistory/cli.py`, `write_report`; `taskhistory/history.py`,
      `Period.cells`.
      Текст входных блоков записывается в CSV без защиты от формул таблиц.
      Например, два снимка с компонентом и исполнителем `=1+1` проходят
      проверку; запуск завершается с кодом 0, обе ячейки CSV содержат
      исходное `=1+1`. При открытии в Excel/LibreOffice текст может стать
      формулой; кавычки CSV этого не предотвращают. То же касается Task ID
      и других свободных полей. Защищать ячейки, начинающиеся с символов
      формулы (`=`, `+`, `-`, `@`) и управляющих символов, например префиксом
      апострофа; добавить проверку экспорта.
      Источник: ревью всех тулз (2026-11-02), локальный запуск CLI на двух
      вымышленных снимках и чтение результата через `csv.reader`.
      Приоритет средний (2026-11-02): CSV предназначен для табличного
      редактора, а свободный текст из Jira не должен исполняться как формула.
