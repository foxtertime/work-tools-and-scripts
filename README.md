# work-tools-and-scripts

Рабочие тулзы и скрипты.

## Тулзы

| Тулза | Описание |
| --- | --- |

_Пока ни одной. Новая тулза добавляется каталогом `tools/<имя>/` и строкой в
этой таблице._

## Структура

```text
tools/<имя-тулзы>/
├── README.md     # назначение, зависимости, точка входа, версия
├── TODO.md       # задачи по этой тулзе
└── ...           # остальное — на усмотрение самой тулзы
```

Внутреннее устройство тулзы не регламентировано: одиночный скрипт, дерево
каталогов, свой пакетный менеджер, любой язык. Обязательны только `README.md`
и `TODO.md`.

## Использование

Тулза самодостаточна: что ей нужно и как её запускать, написано в её
`README.md`. Каталог тулзы копируется или переносится целиком.

## Разработка

Соглашения репозитория — Git Flow, Conventional Commits, Keep a Changelog,
семантическое версионирование — описаны в [CLAUDE.md](CLAUDE.md).
История изменений: [CHANGELOG.md](CHANGELOG.md). Задачи: [TODO.md](TODO.md).
