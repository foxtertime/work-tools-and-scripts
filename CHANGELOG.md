# Changelog

Все значимые изменения этого репозитория документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- `dashboard` (3.6.0): у страницы появились разделы — островок слева
  переключает Builds, всё нынешнее содержимое, и CVE, пока заглушку под
  таблицу уязвимостей в xlsx.
- `vulnsheet` (1.0.0): таблица задач по уязвимостям — разбирает блоки задач
  из тасктрекера, для каждой пары «CVE — компонент» берёт статус, severity,
  CVSS и данные фикса из Red Hat CSAF/VEX и последний билд из koji-тега и
  пишет CSV из двадцати колонок. Битые блоки дословно уходят в отдельный
  файл. Хаб, тег, версия RHEL и стримы VEX для пакетов из модулей Red Hat
  задаются в YAML-конфиге, там же — имена бинарных пакетов, под которыми
  компонент записан в VEX. Умеет обновлять уже ведущуюся таблицу, сохраняя
  ручные колонки: освежать данные koji и VEX или сверять её с новыми блоками
  — пропавшие задачи помечаются `Missing`, новые дописываются в конец.
  Заменяет три разрозненных скрипта.

## [0.2.0] - 2026-09-02

### Добавлено

- `dashboard` (3.5.1): дашборд патчей koji и GitLab — собирает по koji-тегам
  последние билды с учётом наследования, по `extra.source.original_url`
  находит ветку GitLab, классифицирует файлы каталога `PATCH` и показывает
  состояние тегов и изменения между ними одной самодостаточной HTML-страницей.
  Перенесён из отдельного репозитория `patch` без истории коммитов; своя
  история изменений тулзы сохранена в её `CHANGELOG.md`.

### Изменено

- `dashboard` (3.5.1): раздел «Разработка» в `README.md` тулзы приведён к
  соглашениям репозитория. Описание собственного гитфлоу по `master` заменено
  ссылкой на корневой `CLAUDE.md`, названа независимость версии тулзы и версии
  репозитория, генератор фикстур запускается из каталога тулзы, а не из корня.
  Номер версии тулзы при этом не поднят: изменилась только документация.

## [0.1.0] - 2026-09-02

### Добавлено

- Соглашения репозитория в `CLAUDE.md`: Git Flow, Conventional Commits,
  Keep a Changelog, семантическое версионирование на двух уровнях.
- Правило устройства тулзы: обязательны только `README.md` и `TODO.md`,
  внутренняя раскладка каталога не регламентирована — тулза может быть
  одиночным скриптом или многокомпонентной, на любом языке.
- Корневой `README.md` с оглавлением тулз и описанием структуры.
- Корневой `TODO.md` со списком задач уровня репозитория и правилом работы
  со списками.
